# 稳健基金看板

一个给新手用的基金看板：替你挑基金、看估值、算每月买多少、提示哪只该买或该卖。手机、iPad、电脑的浏览器都能打开，可以添加到主屏幕当 App 用。

- 网址：https://hailloe.github.io/money/
- 数据：每个交易日收盘后自动更新，基金详情页显示盘中实时估值
- 持仓：只保存在你自己设备的浏览器里，不会上传到任何地方

> 这是按公开数据和固定规则做出的参考工具，不是投资建议，不保证收益。

---

## 怎么用

1. **我的 → 风险测评**：答 5 道题，系统按结果定股票和债券的比例。
2. **持仓**：照着支付宝“理财 → 基金 → 持有”页，把每只基金的“金额”和“持有收益”抄进来。
3. **看板**：看总资产、配置比例、市场温度，以及本月要做的事。
4. **买卖分析**：每只基金一条建议（买入 / 加仓 / 暂停 / 减仓 / 分批止盈 / 换成更好的），带理由和金额。
5. **每月定投日**：按“本月定投计划”在支付宝买，买完更新持仓，再在看板上“本月打卡”。

换手机或 iPad 时：在旧设备 **我的 → 导出备份**，在新设备 **导入备份**。

### 添加到主屏幕
- iPhone / iPad：用 Safari 打开网址 → 点“分享” → “添加到主屏幕”
- 安卓：用 Chrome 打开 → 右上角菜单 → “添加到主屏幕”

## 文件说明

| 文件 | 作用 | 需要改吗 |
|---|---|---|
| `config.js` | **选基名单、目标比例、买卖规则阈值、每只基金的“我的判断”、风险问卷** | 想换基金、改比例、改规则，只改这里 |
| `data/seed.json` | 不常变的基金信息：费率、经理任职起始、跟踪指数、公告提示 | 基金降费或换经理时手动改 |
| `data/data.json` | 每日数据（净值、收益、回撤、规模、估值、国债收益率） | **不用改**，自动生成 |
| `scripts/update_data.py` | 抓数据、算指标，生成 `data/data.json` | 数据源接口变了才改 |
| `.github/workflows/update-data.yml` | 每个交易日 16:40、21:40（北京时间）自动运行上面的脚本 | 一般不用改 |
| `app.js` | 页面和规则引擎 | 改功能时才动 |
| `style.css` | 苹果 Mac / iOS 风格的样式，浅色深色两套 | 改外观时才动 |
| `index.html` | 页面骨架 | 一般不用改 |

## 规则是怎么算的

所有规则都是写死的，同样的数据永远给出同样的建议。阈值都在 `config.js` 的 `rules` 里。

### 1. 目标比例
风险问卷 5 题，每题 1–4 分，共 5–20 分：≤9 保守、10–13 稳健、14–17 平衡、≥18 进取。
- 第 1 题选“1 年以内要用”→ 只能保守
- 第 3 题选“大跌全部卖出”→ 最多稳健
- **从行为学习**：过去 12 个月打卡里有 2 次“跌了，我卖了”→ 自动降一档
- 偏好里选“不买主动基金”→ 主动基金的比例并入宽基指数

| 档位 | 宽基 | 红利低波 | 债券 | 主动 | 货币 |
|---|---|---|---|---|---|
| 保守 | 20 | 20 | 45 | 5 | 10 |
| 稳健 | 28 | 27 | 32 | 5 | 8 |
| 平衡（默认） | 35 | 30 | 20 | 10 | 5 |
| 进取 | 42 | 33 | 12 | 10 | 3 |

### 2. 每月买多少（估值信号）
- **宽基和主动基金**看沪深300 近 10 年市盈率百分位：<20% 买 2 倍，20–40% 买 1.5 倍，40–60% 买 1 倍，60–80% 买 0.5 倍，≥80% 暂停。
- **红利低波**看“股息率 − 10 年国债收益率”：≥3 个点 2 倍，2–3 是 1.5 倍，1–2 是 1 倍，0.5–1 是 0.5 倍，<0.5 暂停。
- **债券、货币**每月照常买。
- 少买、暂停省下的钱进余额宝；某类比目标少 10 个点以上且不贵时，额外多买 0.5 倍。

### 3. 每只持仓的建议（按顺序判断，命中一条就停）
1. 不在名单里的基金：名字里有你“不想碰”的行业，或者是行业/主动类 → 分 3 个月卖完，换成同类推荐
2. 在名单里但不是推荐的，评分比推荐的低 8 分以上 → 换成推荐基金
3. 估值“很贵”且这只赚了 15% 以上 → 分批止盈，每月卖 10%
4. 这一类比目标多 5 个点以上 → 减仓到目标（货币类则“转出补仓”）
5. 估值“很贵” → 暂停买入，拿着不动
6. 其他 → 按本月定投计划买（低配时显示“加仓”）

### 4. 基金评分（只看长期质量，**不看近 1 年涨幅**，避免追涨）
同类基金之间比较，每项归一化到 0–1 再加权：
- 宽基：费率 40%、规模 25%、近 3 年收益 20%、回撤 5%、成立年限 10%
- 红利低波：费率 35%、规模 25%、近 3 年收益 25%、回撤 10%、成立年限 5%
- 债券：最大回撤 35%、近 3 年收益 30%、规模 20%、费率 15%
- 主动：近 3 年收益 30%、最大回撤 25%、经理任职 25%、规模 10%（80 亿附近最好）、费率 10%

## 怎么改

### 换一只基金
1. 在 `config.js` 的 `funds` 里加一项（写清楚 `code`、`cat`、`why`、`risk`、`exit`），推荐的加 `pick: true` 和 `split`
2. 在 `data/seed.json` 里补上费率（`mgmtFee` 管理费、`custFee` 托管费、`salesFee` C 类销售服务费）
3. 到 GitHub 仓库的 **Actions → 更新基金数据 → Run workflow** 手动跑一次，新基金的数据就有了

### 数据好几天没更新
看板顶部会出现黄色提示。到 **Actions** 页面看最近一次运行的日志，`data.json` 里的 `status` 字段也会写明哪个数据源失败。脚本对每个数据源单独处理，失败时保留上一次的数字。

### 交给别的 AI 维护
把这份 README 和要改的文件一起发给它，说明你想改什么。规则逻辑都在 `app.js` 的 `analyze()` 函数里，阈值在 `config.js`。

## 数据来源
- 基金净值、规模、经理：天天基金 `fund.eastmoney.com/pingzhongdata/{代码}.js`
- 盘中实时估值：天天基金 `fundgz.1234567.com.cn/js/{代码}.js`（交易日 9:30–15:00）
- 指数估值（市盈率、百分位、股息率）：蛋卷基金指数估值
- 10 年期国债收益率：东方财富数据中心
- 指数逐年涨跌：东方财富行情

这些都是公开网页接口，可能随时调整。收益、回撤按累计净值计算，和支付宝显示的可能略有差异。
