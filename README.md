# 稳健基金看板

一个给新手用的基金看板：替你挑基金、看估值、算每月买多少、提示哪只该买或该卖。手机、iPad、电脑的浏览器都能打开，可以添加到主屏幕当 App 用。

- 网址：https://hailloe.github.io/money/
- 数据：每个交易日收盘后自动更新，基金详情页显示盘中实时估值
- 持仓：只保存在你自己设备的浏览器里，不会上传到任何地方

> 这是按公开数据和固定规则做出的参考工具，不是投资建议，不保证收益。

---

## 怎么用

1. **我的 → 风险测评**：答 5 道题，点“保存测评”，系统按结果定股票和债券的比例。做完以后只显示结果，答案收在“查看我的答案”里；要改点“重新测评”。
   **我的 → 偏好**（每月定投金额、定投日、海外比例、趋势规则、不想碰的行业）也一样：平时是收起来的清单，点“编辑偏好”改，改完点“保存偏好”。
2. **持仓**：输入基金代码（6 位数字）点“查找”，照着支付宝“理财 → 基金 → 持有”页填“金额”和“持有收益”，点“保存到持仓”。**最多 5 只**，满了就不让再加。名单外的基金会按名称自动猜类别（可以改）。
   保存后持仓收进“持仓清单”里，平时是收起来的，点开才看到；每一行后面有“编辑”和“删除”（删除要再点一次“确认删除”）。改金额只能点“编辑 → 保存”，不会一碰就改。
3. **看板**：看总资产、配置比例、市场温度，以及本月要做的事。
4. **买卖分析**：每只基金一条建议（买入 / 加仓 / 暂停 / 减仓 / 分批止盈 / 换成更好的），带理由和金额。
5. **每月定投日**：按“本月定投计划”在支付宝买，买完更新持仓，再在看板上“本月打卡”。

换手机或 iPad 时：在旧设备 **我的 → 导出备份**，在新设备 **导入备份**。

### 添加到主屏幕
- iPhone / iPad：用 Safari 打开网址 → 点“分享” → “添加到主屏幕”
- 安卓：用 Chrome 打开 → 右上角菜单 → “添加到主屏幕”

## 年化目标 5%–10%

- 看板“年化目标”卡片：点“开始记录年化”，把当天总资产记为起点（`P.ledger.start / startValue`）。
- **只记进出整个账户的钱**（`P.ledger.txns`，`type: 'in' | 'out'`）：从银行卡转进支付宝买基金记“转入”，卖出后转回银行卡记“转出”。基金之间换都在账户内部，不用记。
- “买卖分析 → 本月定投计划”的“按计划一键记账”：记一笔转入，金额 = 本月计划合计（钱都从银行卡来）；每月只能记一次。
- 年化用资金加权收益率（XIRR）：起点资产和每笔转入算投入，每笔转出和当前总资产算收回。记满 90 天才显示年化，之前只显示累计收益。满一年后，对比“同期全放余额宝”的金额（按 `config.js` 里货币类的 `ret`）。
- 当前配置的长期估算年化和 5% 对比：低于 5%、刚好在下沿（5%–5.5%）、在目标里，各有说明；“短期”档达不到 5% 是正常的。
- “以后大概有多少”：按现在总资产和每月定投，分别用不顺的 2%、你的配置估算、5% 估算 5 年、10 年后的金额，并和只存不投对比。
- 记账和持仓要一起更新：只记账不更新持仓金额，或者反过来，年化都会算错。

## 定投日历提醒

- “我的 → 偏好 → 加到手机日历”：生成 `money-invest-dayN.ics`，包含两个重复事件（时区 Asia/Shanghai，9:30 提醒）：
  - 每月定投日：提醒打开看板、按计划买入、一键记账、更新持仓、打卡
  - 每年 1 月 15 日年度体检：重新测评、看基金经理和规模、看年化进度、导出备份
- iPhone / iPad 用 Safari 打开后点“添加全部”；安卓用日历 App 打开。改了定投日要先删掉旧的提醒再重新添加。代码在 `app.js` 的 `icsText()`。

## 下跌时的冷静助手

- **压力测试**（买卖分析页，`stressCard()`）：按当前持仓算小跌 / 大跌 / 熊市三种情况账户剩多少。熊市用 `config.js` 各类别的 `dd`，小跌、大跌的跌幅写在 `app.js` 的 `STRESS`。目的是在跌之前想清楚能不能扛住，扛不住就重新测评降档。
- **冷静助手**（`calmCard()`）：推荐基金或持有的基金从近一年最高点回撤超过提醒线（债券 3%、宽基和红利 15%、海外和主动 20%，和后台盯盘一致，`DD_LINE`）时，看板顶部和买卖分析页出现。
  - 用这只基金自己过去 3 年的周净值（`curve`）找出跌超提醒线的几段下跌，算最深跌幅、多久回到高点；没有完整记录就直说，不编数字
  - 该做的 / 不该做的 / 可以做的，以及当前估值下规则给的买入倍数
- **“我很想卖掉”**：卖之前的 3 个问题、现在卖会把多少浮亏变成真亏、先等 24 小时、真卖了就在打卡里如实记录。

## 盯盘与 AI 助手（DeepSeek，可选）

**原则：持续盯着，但只在真正有变化时才说话，不天天写文章。**

- **自动盯盘（不用开网站）**：每次 GitHub 更新数据后运行 `scripts/ai_report.py`，和上次的状态对比：
  1. 沪深300、标普500、纳指100 的估值档位变化；红利低波息差档位变化（档位阈值读自 `config.js` 的 `rules`，和网页同一套）
  2. 红利低波两个信号开始打架或不再打架（`divPeCap`）
  3. 推荐基金从近一年最高点回撤超过 15%；之后每再加深 10 个百分点才再提醒，回撤修复到 7.5% 以内后重置
  4. 推荐基金净值超过 `staleDays`（10）天没更新（国庆、春节长假约休市 9 天，不算断更）
  - 没有变化：不调用 AI，只记“上次检查”时间；有变化：DeepSeek 写一条 150 字以内的提醒（没设密钥时用规则文字）
  - 结果在 `data/ai-report.json`：`checked` 上次检查时间，`state` 上次的信号状态，`history` 最近 60 条提醒
  - 第一次运行只记录状态，不发提醒
  - 开启 AI 写提醒：仓库 **Settings → Secrets and variables → Actions → New repository secret**，名字 `DEEPSEEK_API_KEY`
- **网页里的 AI**：我的 → AI 助手，填 DeepSeek API key（只保存在这台设备浏览器的 `money.ai`，不进备份，不上传）
  - 买卖分析页：“让 AI 解读本月建议”、直接提问、盯盘历史提醒；基金详情页：“问 AI 这只基金”
  - 自动解读：打开网站时，只有操作建议变了（按每只基金的建议生成“指纹”对比），或者到了每月定投日，才重新解读
  - 提问时会把持仓金额、本页建议和市场数据发给 DeepSeek（不发名字）
- AI 只负责解释，不改变规则引擎的买卖建议。提示词在 `app.js` 的 `AI_SYSTEM` 和 `scripts/ai_report.py` 的 `SYSTEM`。

## 规则是怎么算的

所有规则都是写死的，同样的数据永远给出同样的建议。阈值都在 `config.js` 的 `rules` 里，规则逻辑在 `app.js` 的 `analyze()` 函数。

### 1. 只拿 5 只基金，目标比例
组合固定 5 只（`config.js` 里 `pick: true`，`maxFunds: 5`）：
沪深300联接A（宽基）、红利低波联接A、博时标普500联接A + 易方达纳指100（海外）、汇添富中短债A（债券）。
**不配余额宝，也不配主动基金**：少买、暂停买的钱就留在你自己的银行卡里；主动基金费用高、要看基金经理，新手用指数基金更省心。
（`cats` 里还留着“主动基金”和“货币”两个类别，只是为了认出旧持仓并建议移出，目标都是 0%。）

风险问卷 5 题，每题 1–4 分，共 5–20 分：≤9 保守、10–13 稳健、14–17 平衡、≥18 进取。
- 第 1 题选“1 年以内要用” → **短期**档：只放债券基金，不碰股票基金
- 第 3 题选“大跌全部卖出” → 最多稳健
- **从行为学习**：最近 12 个月的打卡里有 2 次“跌了，我卖了” → 自动降一档（最低降到保守）
- 偏好“海外比例”可选 20% 或 25%，但海外最多占股票类的 40%（档位低时自动按上限算）；多出来的从宽基、红利低波里按比例匀，债券不动。“短期”档不显示这个选项

| 档位 | 宽基 | 红利低波 | 海外 | 债券 |
|---|---|---|---|---|
| 短期 | 0 | 0 | 0 | 100 |
| 保守 | 20 | 17 | 8 | 55 |
| 稳健 | 27 | 22 | 11 | 40 |
| 平衡（默认） | 37 | 23 | 15 | 25 |
| 进取 | 40 | 25 | 20 | 15 |

**最多 5 只**：持仓页满 5 只就不能再添加。导入的旧数据超过 5 只时（把“本月要开始买的推荐基金”也算进去），规则这样处理：
1. 先合并重复的：同一个指数拿了两只（比如沪深300 的 A 类和 C 类）、或者名单外的，从金额小的开始，分 3 个月卖掉合并到同类那只（显示“换成更好的”或“分批卖出”）。
2. 还超过时，你手里那只备选就当这一类的代表，新钱继续买它（计划里标“用你已有的”），推荐的那只显示“不用买”，不再多开一只。
3. 要合并过去的推荐基金限购（QDII 常见）、这一类又没超配时，卖出来也买不回去，所以显示“先拿着”，不再往里加钱，等限购放开再合并。

海外内部：标普500 占 70%、纳指100 占 30%（`config.js` 里基金的 `split`）。

### 2. 每月买多少（估值信号）
- **宽基**看沪深300 近 10 年市盈率百分位：<20% 买 2 倍，20–40% 1.5 倍，40–60% 1 倍，60–80% 0.5 倍，≥80% 暂停。
- **海外**每只基金看自己跟踪的指数（`config.js` 里的 `val: 'sp500'` 或 `'ndx'`），阈值和宽基一样。宽基里写了 `val: 'a500'` 的基金，在数据里有中证A500 估值时看自己的，没有时看沪深300。
- **红利低波**看“股息率 − 10 年国债收益率”：≥3 个百分点 2 倍，2–3 是 1.5 倍，1–2 是 1 倍，0.5–1 是 0.5 倍，<0.5 暂停。
  但如果红利低波**自身**市盈率分位 ≥ 80%（`divPeCap`），两个信号打架，最多买 1 倍。
- **债券**每月照常买。
- **已经超配**（比目标多 5 个百分点以上）的类别，本月不买。
- 股票类里，某类比目标少 10 个百分点以上、且买入倍数 ≥ 1（不是“偏贵”或“很贵”）时，额外多买 0.5 倍。
- 便宜月份多买的钱，用之前贵的时候少买、留在银行卡里的钱（手头紧就按平时金额买）。
- **限购**：基金有单日限购（`buyCap`）时，一个月按 20 个交易日算最多能买 `buyCap × 20`，超出部分先不买，留在银行卡；计划里写“每天最多买 X，分 N 天买，或设‘每日定投’”。暂停申购又没有限额的，这个月不买。“卖出的钱怎么买”也扣掉本月定投后再按限额分。
- 计划下面写明这个月少买了多少（留在银行卡）或多买了多少。
- 某类没有推荐基金时，那份钱留在银行卡。

### 3. 每只持仓的建议（按顺序判断，命中一条就停）
先找出“整只卖掉”的基金：所在类别目标是 0%（比如“短期”档里的股票基金）、名单外且名字含你“不想碰”的行业、名单外的主动/行业基金、名单外且所在类别超配、超过 5 只时要合并的（见上面“最多 5 只”）。主动基金和余额宝的目标是 0%，所以也在这里：主动基金分批卖出换成指数基金；余额宝里如果是应急钱，直接从持仓里删掉就行，不用卖。
**算超配时，先扣掉这些正在整只卖出的基金**，避免这边减仓、等那只卖完又要买回来。

1. 整只卖掉的基金 → 分批卖出，钱补到占比不够的类别
2. 名单外的其他基金 → 提示“考虑换掉”
3. 在名单里但不是推荐的，**跟踪同一个指数**的推荐基金评分比它高 8 分以上，且两只的费率、3 年收益、回撤数据都齐全 → 分批换成推荐基金
4. 估值“很贵”且这只赚了 15% 以上 → 分批止盈，每月卖 10%，钱转到占比不够、估值不贵的类别（没有就转到中短债）
5. 这一类超配，但估值便宜（买入倍数 ≥ 1.5）→ 持有不买，**便宜时不卖**
6. 这一类超配 → 减仓，超出部分分 3 个月卖（每月卖当前超出的三分之一）
7. 估值“很贵” → 暂停买入，拿着不动
8. 其他 → 按本月定投计划买（低配时显示“加仓”）

**分批卖出**：第一次建议卖出的月份记在 `sellPlans` 里，3 个月（`sellMonths`）内卖完。每月卖“剩余金额 ÷ 剩余月数”，第 3 个月卖光。

**本月卖出的钱怎么买**：所有卖出、止盈的钱加在一起，按各类比目标少多少分给推荐基金（缺得多的多买，最多补到目标；同一类里估值很贵的推荐基金不买，份额改给同类其他能买的）；估值“很贵”的类别不买；分不完的先不买，留在银行卡。卖出建议里写的“钱放进哪里”和这张表用同一个类别列表（限购已经买满的类别不写）。换基的钱直接买同类推荐，不在这张表里。

推荐基金你还没持有的，会显示“开始买入”或“先不买”（估值贵、类别已超配，或者还没设置每月金额），已经用备选代替的显示“不用买”。

**趋势规则（可选，默认关）**：在“我的 → 偏好 → 编辑偏好”打开。**只影响卖，不影响买**。
- 判断：基金净值在约 40 周均线之上（`rules.trend.ma`，按周取点），而且均线比 4 周前高（`slope`），算“上升趋势”（`trendOf()`）。
- 打开后，上升趋势里：第 4 条“分批止盈”先不卖，显示“趋势持有”；第 6 条“超配减仓”放宽到超配 10 个百分点（`widen`）才减。
- 两道硬限制照样卖：估值分位到 90%（`hardPct`）以上，或超配到 10 个百分点以上。跌破均线后，回到平常规则。
- 好处是不会太早卖掉还在涨的；代价是跌回来时可能还回去一部分利润。打开后基金详情页会显示“趋势向上 / 向下 / 走平”。

### 4. 基金评分（只看长期质量，**不看近 1 年涨幅**，避免追涨）
同类基金之间比较，每项归一化到 0.15–1 再加权；缺数据的项按 0.5 计。海外按跟踪的指数分组比较（标普500 只和标普500 比，纳指100 只和纳指100 比），不拿不同指数的历史涨幅互相比：
- 宽基：费率 40%、规模 25%、近 3 年收益 20%、回撤 5%、成立年限 10%
- 红利低波：费率 35%、规模 25%、近 3 年收益 25%、回撤 10%、成立年限 5%
- 海外：费率 35%、规模 25%、近 3 年收益 20%、回撤 10%、成立年限 10%
- 债券：最大回撤 35%、近 3 年收益 30%、规模 20%、费率 15%
- 主动：近 3 年收益 30%、最大回撤 25%、经理任职 25%、规模 10%（80 亿附近最好）、费率 10%

### 5. 用户和习惯
- 每个用户的持仓、测评、偏好、打卡、资产快照分开保存在浏览器的 `localStorage`（键名 `money.v1`）。
- 持仓、测评、偏好都要点“保存”才会改，保存后旁边显示“已保存 时间”；浏览器禁止本地存储时会直接提示保存不了。
- 每次保存持仓，当天记一个资产快照（总资产、收益、股票占比），用来画走势。
- 每月打卡 5 个选项，执行分：全部照做 100、做了一部分 60、没操作 40、追涨或割肉 0，取最近 6 次的平均。
- 导入备份和读取本机数据时都会逐项检查，坏数据会被丢弃，不会让页面卡死。万一页面出错，会显示“导出备份”和“重置所有数据”两个按钮。

## 怎么改

### 换一只基金
1. 在 `config.js` 的 `funds` 里加一项（写清楚 `code`、`cat`、`why`、`risk`、`exit`），推荐的加 `pick: true` 和 `split`；海外基金还要写 `val: 'sp500'` 或 `val: 'ndx'`
   - `why` / `risk` / `exit` 里不要写具体数字（比如“近 3 年涨了 13%”），数字会变，页面上的数字由数据自动生成
2. 费率和限购不用手填：脚本每天从天天基金费率页（`fundf10.eastmoney.com/jjfl_代码.html`）抓管理费 `mgmtFee`、托管费 `custFee`、销售服务费 `salesFee`、申购状态 `buyStatus`、单日限购 `buyCap` / `limit`。抓不到时用上次的数据，再没有才用 `data/seed.json` 里手填的。只在“交易状态”后面一小段里找限额；明确写“开放申购”才清掉限购，“暂停申购”又没写上限时当作这个月买不了。同一指数的推荐基金限购时，不建议把备选基金换过去
3. 到 GitHub 仓库的 **Actions → 更新基金数据 → Run workflow** 手动跑一次，新基金的数据就有了

### 数据好几天没更新
推荐基金净值日期的中位数、或者沪深300 估值日期，超过 5 个工作日（`staleWeekdays`）没变时，看板顶部会出现黄色提示；后台盯盘按 10 个自然日（`staleDays`）发断更提醒。到 **Actions** 页面看最近一次运行的日志，`data.json` 里的 `status` 字段会写明哪个数据源失败。
脚本对每个数据源单独处理，失败时保留上一次的数字；基金净值全部失败或指数估值失败时，任务会标红，GitHub 会发邮件提醒。

目前已知：东方财富的指数月线接口在 GitHub 的服务器上连不通，所以“沪深300 / 红利低波 逐年涨跌”暂时用对应联接基金（006131、007466）的净值涨跌代替，页面上会标明“按联接基金净值”。

### 交给别的 AI 维护
把这份 README 和要改的文件一起发给它，说明你想改什么。规则逻辑都在 `app.js` 的 `analyze()` 函数里（分四步：找整只卖出的基金 → 本月定投计划 → 每只持仓的建议 → 卖出的钱怎么买），阈值在 `config.js`。

## 数据来源
- 基金净值、规模、经理：天天基金 `fund.eastmoney.com/pingzhongdata/{代码}.js`
- 盘中实时估值：天天基金 `fundgz.1234567.com.cn/js/{代码}.js`（交易日 9:30–15:00）
- 指数估值（市盈率、百分位、股息率）：蛋卷基金指数估值，包括沪深300、红利低波、标普500、纳指100
- 中国 10 年期国债收益率：东方财富数据中心
- 美国 10 年期国债收益率：美国财政部官网每日收益率曲线（备用：FRED DGS10）
- 指数逐年涨跌：东方财富行情（连不通时用联接基金净值代替）

这些都是公开网页接口，可能随时调整。收益、回撤按累计净值计算，和支付宝显示的可能略有差异。
